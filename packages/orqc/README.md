# @7nohe/orqc

Short name for [`@7nohe/openapi-react-query-codegen`](https://www.npmjs.com/package/@7nohe/openapi-react-query-codegen), for running it once without installing:

```bash
npx @7nohe/orqc -i ./petstore.yaml
```

Each version runs exactly the same version of `@7nohe/openapi-react-query-codegen`, so `npx @7nohe/orqc@4.0.0` is `@7nohe/openapi-react-query-codegen@4.0.0`.

In a project, install the main package instead and run its `orqc` command:

```bash
npm install -D @7nohe/openapi-react-query-codegen
npx orqc -i ./petstore.yaml
```

Documentation: https://orqc.7nohe.dev
