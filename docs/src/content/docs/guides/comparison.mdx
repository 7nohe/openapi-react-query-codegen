Orval, Kubb, Hey API and openapi-react-query also turn an OpenAPI document into code for TanStack Query. This library is the one built only for React and TanStack Query v5, and that focus is where its advantages come from.

## What sets it apart

- **Everything is generated, with nothing to configure.** One command writes a hook, a suspense hook, a `queryOptions` factory, a prefetch function, an `ensureQueryData` function and a key function for every GET operation, and a mutation hook for the rest. With Orval and Kubb several of these are options you turn on. Hey API, and Kubb by default, generate options factories that you wire to the hooks yourself.
- **It is the fastest on every specification we measured.** The GitHub REST API ({githubOperations} operations) takes {seconds[0].value.toFixed(2)} seconds. The other four take between {Math.min(...others(seconds)).toFixed(2)} and {Math.max(...others(seconds)).toFixed(2)} seconds.
- **It installs the least.** The generator adds {addedPackages[0].value} packages to a project. The others add between {Math.min(...others(addedPackages))} and {Math.max(...others(addedPackages))}.
- **Its output compiles.** For the Stripe and GitHub APIs, `tsc` with `strict` reports no error in the generated code. That is not true of every generator: see the table below.
- **Server rendering is covered.** It is the only tool here that generates `ensureQueryData` functions, and prefetch functions come without an option. There are examples for [Next.js](/examples/nextjs/), [React Router](/examples/react-router/) and [TanStack Router](/examples/tanstack-router/).
- **It is made for CI and for coding agents.** [`--check`](/guides/ci-and-agents/) fails the build when the committed output is out of date, `--json` prints errors as JSON, and [`--agentsMd`](/guides/ci-and-agents/#coding-agents-a-guide-in-your-agentsmd) keeps a guide in your `AGENTS.md` that cut what an agent had to read by a quarter to a third in our runs.
- **The output is stable.** The client and the hooks come from one package and change in a breaking way only in a major version, with a migration guide.

## Compared with Orval

Choose this library when you want React and TanStack Query without a configuration file. Suspense hooks, prefetch functions and `ensureQueryData` functions are there for every operation, where [Orval](https://orval.dev) has an option for each of the first two and none for the third. The generator adds {addedPackages[0].value} packages where Orval adds {pick(addedPackages, "orval")}, generates the GitHub API in {seconds[0].value.toFixed(2)} seconds where Orval takes {pick(seconds, "orval").toFixed(2)}, and its output for the Stripe API compiles where Orval's had {pick(typeErrors("stripe"), "orval")} type errors in our run.

Choose Orval when you need Vue, Svelte, Solid or Angular, SWR, Zod or Valibot schemas, mock data that is random, or per-operation overrides in a configuration file.

## Compared with Kubb

Choose this library when the fixed output is what you want. [Kubb](https://kubb.dev) is a plugin system: its React Query plugin generates `queryOptions` and `mutationOptions` factories by default and hooks when you set `hooks: true`, and you compose the rest in `kubb.config.ts` from plugins for the types, the client and the queries. Here there is one command and one package, {addedPackages[0].value} packages installed where that Kubb setup adds {pick(addedPackages, "kubb")}, and prefetch and `ensureQueryData` functions that Kubb does not generate.

Choose Kubb when you want to compose the output from plugins, write your own, or generate Vue Query, SWR or Zod code from the same configuration.

## Compared with Hey API

Choose this library when you want ready-made hooks. The documented output of the TanStack Query plugin of [Hey API](https://heyapi.dev) (`@hey-api/openapi-ts`) is options factories and query keys, which you pass to `useQuery`, `useInfiniteQuery` and `useMutation` yourself. It has no suspense, prefetch or `ensureQueryData` helpers. Hey API is before 1.0 and asks you to pin an exact version, while this library changes its output in a breaking way only in a major version. In our run, the output of 0.99.0 for the Stripe API had {pick(typeErrors("stripe"), "hey-api")} type errors, and that version did not run in a project with TypeScript 7.

Up to v3 this library used `@hey-api/openapi-ts` to generate its client. Since v4 it has its own generator, which removed most of the packages it used to install. See [Migrating to v4](/guides/migrating-to-v4/).

Choose Hey API when you need a framework other than React, an HTTP client other than fetch and axios, or Zod or Valibot validation.

## Compared with openapi-typescript and openapi-react-query

Choose this library when you want a project that is maintained. [openapi-typescript](https://openapi-ts.dev) announced that it is [in maintenance mode](https://github.com/openapi-ts/openapi-typescript/issues/2874) from September 2026 and will get no more updates, and `openapi-fetch` and `openapi-react-query` with it. [Migrating from openapi-react-query](/guides/migrating-from-openapi-react-query/) shows the move step by step.

The approach differs too. openapi-typescript generates types only, and you call `$api.useQuery("get", "/pets/{petId}", ...)` with the method and the path as strings. Here every operation is a named hook (`useFindPetById`) that an editor can complete and a search can find, with key functions for invalidation and prefetch functions for the server, and no runtime package between your code and `fetch`.

That approach keeps very little generated code in the repository, which is its appeal. If that matters more to you than named hooks, it still works with the versions that exist today.

## When another tool fits better

This library is deliberately narrow. Another tool is the better choice when:

- You use Vue, Svelte, Solid or Angular. The hooks are for React.
- You want Zod or Valibot schemas generated for runtime validation. This library writes JSON Schema constants only.
- You want mock data that is random, or mocks that keep state. The generated MSW handlers answer with fixed values from the specification.
- You need an HTTP client other than fetch or axios.
- You want to change the shape of the generated code. There are flags, but no templates or plugins.

## In short

For a React application on TanStack Query v5, this library gives you the most generated code for the least setup: typed hooks and server-side helpers for every operation from one command, the smallest install and the fastest generation of the tools compared here, and output that compiles. Reach for one of the others when you need what it leaves out: another framework, runtime validation or a plugin system.
