---
title: Migrating from openapi-react-query
description: Move from openapi-typescript + openapi-fetch + openapi-react-query to generated TanStack Query hooks.
---

[openapi-typescript](https://github.com/openapi-ts/openapi-typescript) has [entered maintenance mode](https://github.com/openapi-ts/openapi-typescript/issues/2874): no further updates, including security patches. If you use `openapi-typescript` with `openapi-fetch` and `openapi-react-query`, this guide shows how to move to OpenAPI React Query Codegen.

## How the two approaches differ

| | openapi-react-query | OpenAPI React Query Codegen |
|---|---|---|
| Approach | Runtime wrapper typed by a generated `paths` type | Generated, per-operation hooks and `queryOptions` factories |
| Call style | `$api.useQuery("get", "/pets/{id}", ...)` — method and path strings | `useFindPetById({ path: { id } })` — one function per operation |
| Fetch layer | `openapi-fetch` | Client generated by [@hey-api/openapi-ts](https://github.com/hey-api/openapi-ts) (fetch or axios) |
| `queryOptions` | `$api.queryOptions(...)` | `findPetByIdOptions(...)` |
| SSR (`prefetchQuery`, `ensureQueryData`) | Build it yourself from `queryOptions` | Generated per operation |
| Query keys | Derived from method, path and params | Exported key constants and key functions |
| Suspense / infinite | `useSuspenseQuery` / `useInfiniteQuery` | Generated `useXxxSuspense` / `useXxxInfinite` / `useXxxSuspenseInfinite` |

The move is a rewrite of call sites, not a drop-in swap. Hook names come from each operation's `operationId`, so make sure your schema has stable `operationId`s.

## 1. Replace the tooling

```bash
npm uninstall openapi-typescript openapi-fetch openapi-react-query
npm install -D @7nohe/openapi-react-query-codegen
npx openapi-rq -i ./openapi.yaml
```

Keep `@tanstack/react-query` 5.x installed. Replace the `openapi-typescript` step in your scripts with `openapi-rq`.

## 2. Replace client setup

Before:

```ts
import createFetchClient from "openapi-fetch";
import createClient from "openapi-react-query";
import type { paths } from "./schema";

const fetchClient = createFetchClient<paths>({ baseUrl: "https://myapi.dev/v1/" });
export const $api = createClient(fetchClient);
```

After — configure the generated client once, at app startup:

```ts
import { client } from "./openapi/requests/services.gen";

client.setConfig({ baseUrl: "https://myapi.dev/v1/" });
```

See the [introduction](/guides/introduction/) for the exact setup of the client you generate.

## 3. Replace call sites

Parameters are flat: `params.path` becomes `path`, `params.query` becomes `query`. The request body stays under `body`.

### Queries

Before:

```tsx
const { data } = $api.useQuery("get", "/pets/{id}", {
  params: { path: { id: 5 } },
});
```

After:

```tsx
import { useFindPetById } from "./openapi/queries";

const { data } = useFindPetById({ path: { id: 5 } });
```

Or use the `queryOptions` factory, which composes with any TanStack Query API:

```tsx
import { useQuery } from "@tanstack/react-query";
import { findPetByIdOptions } from "./openapi/queries";

const { data } = useQuery(findPetByIdOptions({ path: { id: 5 } }));
```

### Mutations

Before:

```tsx
const { mutate } = $api.useMutation("post", "/pets");
mutate({ body: { name: "Rex" } });
```

After:

```tsx
import { useAddPet } from "./openapi/queries";

const { mutate } = useAddPet();
mutate({ body: { name: "Rex" } });
```

### Infinite queries

Before:

```tsx
$api.useInfiniteQuery(
  "get",
  "/pets",
  { params: { query: { limit: 10 } } },
  { getNextPageParam: (lastPage) => lastPage.nextPage, initialPageParam: 0 },
);
```

After — the page parameter is wired by the generator. Pass `--pageParam` and `--nextPageParam` (and optionally `--initialPageParam`) to `openapi-rq` to match your API, then:

```tsx
import { useFindPetsInfinite } from "./openapi/queries/infiniteQueries";

const { data, fetchNextPage } = useFindPetsInfinite({ query: { limit: 10 } });
```

See [CLI options](/guides/cli-options/) and [infinite query usage](/guides/usage/#using-the-generated-useinfinitequery-hooks) for details.

### Server-side prefetching

With openapi-react-query you build prefetching yourself from `queryOptions`. Here you also get `prefetchQuery`, `prefetchInfiniteQuery` and `ensureQueryData` functions per operation in `prefetch.ts` and `ensureQueryData.ts` — see the [Next.js example](/examples/nextjs/).

## What you give up

- The 1 kb runtime footprint: the generated clients are larger than `openapi-fetch`.
- Path-string call style. Each operation is its own function, so renaming an `operationId` renames the hook.
- Non-React frameworks: this library targets React only.
